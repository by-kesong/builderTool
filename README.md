# builderTool - Git 多项目分支管理工具 v1.1

一个 PyQt5 桌面工具，用于集中管理工作目录下的多个 Git 项目。

![软件主界面](assets/interface.png)

## v1.1 新增核心功能

- **安全密码锁屏系统**：支持设置解锁密码，进入软件需要输入解锁；并且支持在软件中直接修改密码。
- **并发多线程批量打包控制台**：
  - **多项目并发打包**：支持在主界面勾选多个项目一键启动批量打包。
  - **并发控制**：可在界面上实时调整最大并发打包进程数限制（默认 3）。
  - **日志流查看**：可在控制台实时查看每个编译任务的控制台输出日志。
  - **防重复打包**：对于在当前会话中已经打包成功的项目会自动跳过，避免重复编译；支持手动右键选择重新打包。
  - **单项/整组中止**：支持一键“全部中止”正在编译和排队的项目，也支持右键点击某项目进行“单项中止”。
  - **物理强杀子进程树**：完美解决了 Windows 平台下 QProcess 无法彻底杀死 `node.exe`、`vite`、`webpack` 编译子进程的问题。
  - **后台持续编译**：关闭打包控制台会自动隐藏到系统后台持续运行，不会中断编译，在主界面上点击 `📦 打包` 即可随时重新呼出。
  - **耗时人性化转换**：自动将超过 60 秒的累计耗时转换为分秒表示（如 `1m 19s`），便于直观查看。
  - **置顶完成提醒**：当所有打包任务完成时，会自动闪烁任务栏并强制置顶弹出汇总提示框。
- **删除远端分支安全二次确认**：当执行删除远端分支（`origin`）操作时，弹出高亮警告框确认，防止误删危险分支。
- **切换分支异常阻拦保护**：修复了在切换分支被 Git 警告（如本地未暂存的修改将被覆盖）而阻止时，主界面分支展示由于未恢复而产生状态不一致的 bug。

## 基础功能

- 扫描目录下所有 git 项目并列表展示
- 克隆新仓库到指定目录
- 读取/切换本地分支（切换前自动检测未提交代码，防止冲突）
- 常用操作：status / pull / add+commit（提交前弹窗确认改动文件）/ push
- 基于指定基准分支创建新分支并自动切换（支持中文分支名）
- 全站点 IP 检索替换（先预览匹配，再执行替换）
- 操作日志面板：完整记录每条 git命令及输出，错误红色显示

## 环境要求

- Python 3.7+
- 已安装 git 并加入 PATH，且配置好凭证（SSH key 或凭证缓存）

## 安装与运行

```bash
pip install -r requirements.txt
python main.py
```

## 项目结构

```
builderTool/
├── main.py               # 入口
├── requirements.txt
├── builderTool.spec      # PyInstaller 打包配置文件
└── app/
    ├── config.py         # 配置持久化（~/.buildertool_config.json）
    ├── git_ops.py        # git 命令封装（参数列表方式，支持中文分支名）
    ├── ip_replace.py     # 全站点 IP 检索/替换
    ├── worker.py         # 后台线程（QThread）
    ├── lock.py           # 密码锁屏模块
    ├── batch_build.py    # 批量打包控制台模块
    └── main_window.py    # 主窗口 UI 与交互
```

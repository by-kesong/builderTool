# builderTool - Git 多项目分支管理工具 v1.0.1

一个 PyQt5 桌面工具，用于集中管理工作目录下的多个 Git 项目。

![软件主界面](assets/interface.png)

## v1.0.1 新增核心功能

- **项目列表树形分组与拖拽排序**：将原扁平项目列表升级为树形分组结构，支持新建、重命名、删除自定义分组；支持项目在分组之间及组内自由拖拽排序，排序结果自动本地化持久存储。
- **分组快捷右键调整**：右键分组头部支持“置顶”、“上移一位”等快捷排序操作，项目管理更高效。
- **快捷工具栏整合**：将“全选”、“取消全选”与“展开全部”、“折叠全部”整合迁移至底部的同一行工具栏，界面布局更显紧凑与美观。
- **未分组项目自动归底**：未加入分组的项目自动归为“未分组”并固定排在列表最末尾，保证界面整洁。
- **启动自动强杀残留进程**：在软件启动执行时，优先检测并物理强杀原有残留的打包编译子进程（如 node、vite），防止后台端口被占用和端口冲突。
- **修复 MCP 相关 Bug**：修复了在特定环境下的 MCP 相关调用与执行问题，软件运行更为稳定。

## v1.0.0 新增核心功能

- **安全密码锁屏系统**：支持设置解锁密码，进入软件需要输入解锁；并且支持在软件中直接修改密码。
- **并发多线程批量打包控制台**：
  - **多项目并发打包**：支持在主界面勾选多个项目一键启动批量打包。
  - **并发控制**：可在界面上实时调整最大并发打包进程数限制（默认 3）。
  - **日志流查看**：可在控制台实时查看每个编译任务的控制台输出日志。
  - **防重复打包**：对于在当前会话中已经打包成功的项目会自动跳过，避免重复编译；支持手动右键选择重新打包。
  - **单项/整组中止**：支持一键“全部中止”正在编译 and 排队的项目，也支持右键点击某项目进行“单项中止”。
  - **物理强杀子进程树**：完美解决了 Windows 平台下 QProcess 无法彻底杀死 `node.exe`、`vite`、`webpack` 编译子进程的问题。
  - **后台持续编译**：关闭打包控制台会自动隐藏到系统后台持续运行，不会中断编译，在主界面上点击 `📦 打包` 即可随时重新呼出。
  - **耗时人性化转换**：自动将超过 60 秒的累计耗时转换为分秒表示（如 `1m 19s`），便于直观查看。
  - **置顶完成提醒**：当所有打包任务完成时，会自动闪烁任务栏并强制置顶弹出汇总提示框。
- **删除远端分支安全二次确认**：当执行删除远端分支（`origin`）操作时，弹出高亮警告框确认，防止误删危险分支。
- **切换分支异常阻拦保护**：修复了在切换分支被 Git 警告（如本地未暂存的修改将被覆盖）而阻止时，主界面分支展示由于未恢复而产生状态不一致的 bug。

## v1.0.0 新增核心功能

- **教学部署管理面板（分栏布局与表格录入升级）**：
  - **主界面左右分栏布局**：废除原顶部选项卡，重构为左右分栏，左侧为多项目列表，右侧为教学部署面板，信息展示更加高效直观。
  - **勾选启动打包限制**：批量打包时，必须勾选左侧列表的复选框方能启动打包；未勾选任何项目时将进行警告拦截，确保打包操作准确。
  - **部署图片上传与预览**：表格新增“图片”列，支持上传本地图片并自动保存至工作空间；提供防走样大图缩放预览、调用系统查看器打开，以及一键清除功能。
  - **录入日期选择**：新增“录入日期”列，默认使用当天日期，支持通过下拉日历控件（`QDateEdit`）进行可视化挑选与保存。
  - **版本/模式下拉选项**：版本列升级为可编辑的下拉菜单（`QComboBox`），预设“新版”、“旧版”、“新版-t1”，亦可手动录入自定义模式。
  - **精细样式与主题统一**：表格中所有的下拉框、日期选择、上传/查看/删除按钮在深浅色模式下的配色样式均完美统一，风格高度一致。
  - **检索过滤与分页器**：支持按学校、备注等全字段实时模糊过滤，且自带客户端分页器（支持10/20/50条分页），保证大数据量下的响应速度。
  - **兼容性迁移**：支持旧版本配置的平滑升级，自动为缺失新字段（如日期、图片）的历史部署数据补全默认值。

## 基础功能

- 扫描目录下所有 git 项目并列表展示
- 克隆新仓库到指定目录
- 读取/切换本地分支（切换前自动检测未提交代码，防止冲突）
- 常用操作：status / pull / add+commit（提交前弹窗确认改动文件）/ push
- 基于指定基准分支创建新分支并自动切换（支持中文分支名）
- 全站点 IP 检索替换（先预览匹配，再执行替换）
- 操作日志面板：完整记录每条 git命令及输出，错误红色显示

## 环境要求

- Python 3.7+
- 已安装 git 并加入 PATH，且配置好凭证（SSH key 或凭证缓存）

## 安装与运行

```bash
pip install -r requirements.txt
python main.py
```

## 项目结构

```
builderTool/
├── main.py               # 入口
├── requirements.txt
├── builderTool.spec      # PyInstaller 打包配置文件
└── app/
    ├── config.py         # 配置持久化（~/.buildertool_config.json）
    ├── git_ops.py        # git 命令封装（参数列表方式，支持中文分支名）
    ├── ip_replace.py     # 全站点 IP 检索/替换
    ├── worker.py         # 后台线程（QThread）
    ├── lock.py           # 密码锁屏模块
    ├── batch_build.py    # 批量打包控制台模块
    └── main_window.py    # 主窗口 UI 与交互
```
